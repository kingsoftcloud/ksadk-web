## Canonical contract and integration

- `RuntimeConversationIngress` maps RuntimeEvent/v2 into the existing `ConversationItemReducer`; HttpConversationClient injects its sole visible reducer. Live, full history and replay use this ingress. Existing unscoped v1 history retains its compatibility path.
- In `agent-block-v1`, canonical item identities are `JSON.stringify([runId, scopeId, nativeItemId])`. A descriptor uses its actual RuntimeEvent item ID. Other events use the event ID in the third position. Flat compatibility keeps bare IDs. Child content requires an already-observed descriptor and points `parentItemId` to that descriptor's canonical item ID. Descriptor/root-trigger arrival order may vary; the trigger's first-seen position owns the AgentBlock.
- `nativeRef` preserves source `framework`, `protocol`, `eventId`, `cursor`, `runId`, and `itemId` when present. Additive `scopeId`, `runtimeItemId`, `parentScopeId`, and canonical-event `phase` keep native and canonical locators separate. `output_refs` resolves via `runtimeItemId`.
- `agent` uses `conversation.item.agent/v1` with the native `execution.scope/v1` descriptor payload. Exported `ExecutionScopeDescriptor` and `AgentExecutionStatus` define the fields. Native `tool_result` stays Conversation `tool_call`/`conversation.item.tool-call/v1`, with `sourceKind` and `executionStatus`. Source items stay separate; only the presentation joins by `(runId, scopeId, callId)`. Result-first observations remain honest orphans until their matching call appears.
- `agentBlockRendererCatalog` is compiled locally. Profile negotiation requires input capability `ksadk.presentation`, output capability `agent.block`, and this trusted renderer. Only then does the client add `extensions['ksadk.presentation']={profile:'agent-block-v1'}`. The codec accepts only `agent-block-v1`/`flat-v1`, with no extra profile fields.
- `agent.block.mode=native` selects native ConversationItem authority; `translated` selects RuntimeEvent compatibility authority. Legacy transports may set `ConversationClientOptions.ingressLane`; disagreement with declared authority fails before sending. Frames from the other lane cannot take ownership, including when they arrive first.
- Entry points remain POST `/api/v1/builds/{buildId}/conversation:stream` and GET `/api/v1/runs/{runId}/events?after={cursor}`. Negotiated replay adds `presentationProfile=agent-block-v1`, and retains Last-Event-ID. Backend enforcement of persisted profile/cursor agreement is an SDK/server responsibility.
- `AgentBlockView` is exported from `@kingsoftcloud/ksadk-web/chat/timeline`. It starts collapsed, updates expanded content through existing text/tool/artifact renderers, and shows descriptor status independently of root status. Unknown tool execution is visibly unknown. Nested delegation remains passive at one remote detail level.
- Optional `AgentBlockActions.cancel` receives `{sessionId, runId, scopeId, parentItemId}`. There is no raw A2A request or invented transport endpoint. Hosted UI exposes no cancel action until a host supplies the typed surface action. Existing Interaction/v1 records and revision-CAS submission own interaction responses; no generic unaddressed interaction button was added.
- Flat output uses only root final references, or explicitly referenced child output in a pure delegation. It does not concatenate root plus all children. Public tool observations receive credential/diagnostic/private-URL filtering; raw child reasoning is hidden unless explicitly public.

## Quality review follow-up (three findings)

- Flat-v1 now keeps root items in the legacy bare-ID reducer and stores child-scope facts in a separate reducer with canonical `[runId, scopeId, itemId]` identities. The public snapshot combines both stores for projection, so a child and root item with the same native ID remain distinct while flat root callbacks and output keep the legacy identity.
- AgentBlock projection resolves the full root trigger family by `(runId, scopeId, callId)`. The initiating call and a separately emitted result are both absorbed into the AgentBlock regardless of whether the result arrives before or after the scope descriptor; the result no longer escapes as a duplicate orphan row.
- Public tool-value filtering normalizes credential keys before matching, detects credential assignments embedded in strings, and rejects credential-bearing or internal HTTP(S) URLs. Coverage includes camel-case and punctuation variants, compact/integer/hex IPv4, IPv4-mapped IPv6, loopback, link-local, and IPv6 unique-local addresses while retaining public IPv4 and IPv6 URLs.

Fresh validation after this follow-up passed **461 tests in 53 files**, **130 Node contract tests**, lint, all four `build:all` targets, **7/7 canonical Conversation browser tests**, and **5/5 reconnect browser tests**. The reconnect suite first ran concurrently with the canonical browser suite and one old recovery test exceeded its five-second assertion timeout; that individual test and then the complete reconnect suite passed immediately in isolation without code changes. Build output retains the repository's existing browserslist-age and chunk-size warnings.
